1.	**Branching:** Create your feature branch off of `main` (unless you strictly need unreleased code from `dev`).
2. **Test Locally:** Run the tests locally using the commands in the `README.md`.
3.	**Pull Requests:** Submit all PRs to the `dev` branch.
4.	**Software Review:** A maintainer will review and merge your PR into `dev`.
5.	**Hardware Review:** The lab team will test `dev` on the physical hardware and merge it into `main` if successful.
